# PDF 2.0 syntax fixtures

English | [Français](README.fr.md)

Original MIT fixtures generated by `tools/build_pdf20_fixture.py` using pypdf
6.20.1 and qpdf 12.4.2, independently from the PHP writer. The manifest records
their byte lengths, SHA-256 identities and expected header/catalog versions.

`header.pdf` has a PDF 2.0 header; `catalog.pdf` has a PDF 1.7 header and a
PDF 2.0 catalog version; `object-streams.pdf` uses PDF 2.0 xref/object streams.
Each contains one blank page and a UTF-8 BOM catalog string. Tests interpret
that string explicitly using the core PDF 2.0 text decoder. The generic reader
keeps the original bytes unchanged. Independent checks use pypdf and qpdf.
